# File-Based Attendance Management System

### Overview
The File-Based Attendance Management System is a Java console application developed to manage student attendance records using File Handling concepts.  
The project stores attendance data permanently in a text file, simulating a real-world college attendance system.

This project demonstrates the practical implementation of:
- File Handling
- Object-Oriented Programming (OOP)
- Exception Handling
- Java Time API
- Menu-Driven Programming

## Features

✔ Mark student attendance  
✔ Store attendance records permanently in file  
✔ View all attendance records  
✔ Search attendance by student name  
✔ Prevent duplicate attendance for same day  
✔ Generate attendance summary  
✔ Calculate attendance percentage  
✔ Real-world college attendance simulation  
✔ Exception handling for safe execution

## How to Run the Project

### Step 1: Open Eclipse IDE

Open Eclipse and create a new Java Project.

### Step 2: Create Java Class

Create a class named:
```
AttendanceSystem
```
Paste the complete source code into the file.

### Step 3: Run the Program

Right Click on:
```
AttendanceSystem.java
```
Select:
```
Run As → Java Application
```
