# Inventory Management System (Java + Swing)

#### A Java-based Inventory Management System with a graphical user interface built using Swing, designed to manage products, track stock levels, and record transactions.

## Features
- ➕ Add Product
- 📉 Sell Product
- 📦 Restock Product
- 📋 View Inventory (Table UI)
- ⚠️ Low Stock Alerts
- 🧾 Transaction History
- 💾 File Persistence (data saved locally)
- 🔍 Input Validation & Error Handling
- ⚡ Optimized using HashMap (O(1) access)

## Project Structure

##  Tech Stack
1. Java (Core Java)
