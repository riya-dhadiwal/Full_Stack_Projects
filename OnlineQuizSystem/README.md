# 🎮 Online Quiz Application (Java Console-Based)


## 📌 Overview

### This project is a console-based Quiz Application developed in Java that simulates a real-world quiz game with engaging features like lifelines, scoring system, leaderboard, and fun feedback.

#### It demonstrates core programming concepts such as:
- Object-Oriented Programming (OOP)
- File Handling
- Collections Framework
- Control Flow & Logic Building

## 🚀 Features
### Core Features
- Multiple-choice questions (MCQs)                  
- Question randomization (Shuffle)
- 🎮 Gamification Features                           
- 🔥 Streak system (bonus points)
- 💰 Points system                                   
- 🎭 Fun feedback messages
- 💡 Fun facts after each question                   
- 🧠 Lifelines
- 50-50 (removes two wrong options)                  
- Skip question
- 🏆 Leaderboard                                     
- Stores scores using file handling

## 🛠️ Technologies Used
1. Java (Core Java)
2. OOP Concepts
3. Java Collections (ArrayList, Collections)
4. File Handling (BufferedReader, BufferedWriter)

## ▶️ How to Run
Step 1: Clone the Repository
git clone https://github.com/your-username/online-quiz-app.git
Step 2: Navigate to Project Folder
cd online-quiz-app
Step 3: Compile the Code
javac QuizGame.java
Step 4: Run the Application
java QuizGame
