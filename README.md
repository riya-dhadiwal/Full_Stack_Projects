Student Management System
(Console-Based Java Application)

Project Overview

The Student Management System is a console-based Java application that allows users to manage student records efficiently.

This project demonstrates core Java programming concepts including:
1) Object-Oriented Programming (OOP)
2) ArrayList usage
3) Exception Handling
4) Menu-driven programs
5) Encapsulation

Objective

To build a menu-driven Java application that allows users to:
- Add student details
- View all students in table format
- Search students by ID, Name, and Course
- Update student information
- Delete student records
- View system statistics
- Count students per course

🛠 Technologies Used

- Java (JDK 8+)
- Eclipse IDE
- Core Java Libraries

Concepts Covered:

- Classes & Objects
- ArrayList
- Methods
- Switch Case
- Scanner
- Encapsulation
- Exception Handling
- CRUD Operations
